# 快速導覽

> 這是 **陳育霖** 在 **中研院 2025** 的專題。左側可切換章節，或點下方連結直達重點。  
> 目標是建立一套 **可大量處理、交接、可控且可驗證** 的 Qt `.ts` 翻譯流程。

- 先看 **[軟體介紹](intro.md)** 與 **[操作頁面](guide.md)** 了解功能與常見問題  
- 選擇翻譯模式：**[Online GPT](app_api)** 或 **[Local LLM](app_local)**

---

## 快速開始

1. 進入 **[Online GPT](app_api)**（或改用 [Local LLM](app_local)）。
2. 設定翻譯模型
   - Online：填入 `API Key`、確認 `Base URL` 與 `Model`
   - Local：設定模型後產生 Notebook 於本機執行
3. 上傳待翻譯的 `.ts` 檔案。
4. (可選)上傳 **Glossary**（`CSV / ODS`，欄位為 `en, zh` 或 `英文名稱, 中文名稱`）。
5. (可選)上傳 **舊版 `.ts`**：當 `<source>` 完全相同時，會直接沿用既有翻譯以節省成本。
6. 設定 `Batch` 與 **處理筆數上限**，先進行小量試跑。
7. 確認格式與結果無誤後，再放大批次並下載輸出 `qgis_zh-Hant.ts`。

```{tip}
Glossary 可同時上傳多個檔案，系統會自動合併。  
建議先用小筆數抽檢(如: 100～300 筆)，再進行完整翻譯。
