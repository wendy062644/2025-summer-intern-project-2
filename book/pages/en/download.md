# QGIS Translation File Downloads (TS / QM)

> Before placing `qgis_3.XX_zh-Hant.qm` into `QGIS 3.XX.X\apps\qgis-ltr\i18n`  
> you must rename it to `qgis_zh-Hant.qm` so QGIS can load it.

## Notes

Each dataset includes:
- `.ts` source translation file
- Compiled `.qm` file (ready to deploy)

These translation files were produced with assistance from Large Language Models (LLMs), followed by manual review and correction.  
For the full translation workflow and project description, see:
https://data.depositar.io/organization/about/qgis-traditional-chinese-translation-files
